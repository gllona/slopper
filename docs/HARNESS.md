# Harness reference (v0.2.0)

> Generated by `npm run harness:docs` from `harness/`. Do not edit by hand.

A scene (`scene.json`) is declarative JSON: the harness turns it into a sanitized, animated SVG. See `docs/DESIGN.md` §9.

## Artboard

- Square **1080×1080**. Safe area: **60 px** margin. Labels and speech bubbles must stay inside it.
- At most **6 words** of text in the art (labels + bubbles). The joke lives in the phrase.
- Place elements with a named anchor (`"at": "left-third"`) or a normalized point (`"at": {"x": 0.3, "y": 0.8}`), or attach them to another element (`"attachTo": "bot", "side": "top"`).
- Grounded components (they stand on the ground line) have their origin at the **bottom center**; floating ones at their **center**.
- Optional per element: `scale` (0.1–4), `offset` [dx, dy] px nudge, `rotate` (deg), `flip` (mirror), `opacity`.

### Anchors

`top-left`, `top-center`, `top-right`, `center-left`, `center`, `center-right`, `bottom-left`, `bottom-center`, `bottom-right`, `left-third`, `center-third`, `right-third`, `ground`, `sky`

Grid anchors are the centers of a 3×3 grid over the safe area. `left-third`, `center-third`, `right-third`, and `ground` sit on the ground line (the horizon of the background, or 78% of the height); `sky` is high in the middle.

### Backgrounds

`background.type`: `solid`, `sky-ground`, `split`, `rays`, `grid`. Omit it to use the style card's default. `horizon` (0.3–0.9) sets the ground line; `color`/`color2` take palette tokens.

## Animation

```json
"animation": { "durationSec": 6, "holdSec": 2, "beats": [ { "t": 0, "target": "bot", "action": "walk-in", "from": "left" } ], "ambient": { "target": "dc", "action": "blink" } }
```

- Story beats: setup → action → punchline → hold. `durationSec` 3–9 s; plays once and rests on the final frame.
- **The final frame must tell the joke alone** (it is the still, the social image, and the reduced-motion view).
- Beats on the same element and channel must not overlap in time. Each beat may set `dur` (s) and `ease`.
- Eases: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `bounce`.
- `ambient` (optional, max one element): `blink`, `pulse`, `sway` — a slow loop that prefers a component part (lights, antenna, rays, steam).

## Style cards

Components draw with roles, never literal colors: `r-body`, `r-body-alt`, `r-accent`, `r-accent-2`, `r-ink`, `r-paper`, `r-line`, `r-thin`, `r-shade`, `r-glow`, `r-text`. Raw SVG should use these classes too.

### `blueprint` — Blueprint

A technical drawing: crisp white lines on deep blueprint blue, over a fine grid. Shapes are mostly outlines with pale translucent fills; one yellow highlight marks the point of the joke.

- Mood: technical, precise, dry, engineered, deadpan
- Palette: bg `#1C4E89`, ink `#EEF4FF`, accent1 `#FFD35C`, accent2 `#79A9DE`, paper `#2A64A5`
- Font: ibm-plex-mono-700 · default background: grid · texture: none · shadow: none

### `paper-cutout` — Paper cutout

Flat layers of cut colored paper on kraft card. No outlines: shapes are separated by color and a soft shadow under each layer, like a paper collage photographed from above.

- Mood: handmade, calm, tactile, cozy, storybook

- Font: bricolage-grotesque-800 · default background: split · texture: grain · shadow: soft

### `riso-duotone` — Riso duotone

A two-ink risograph print (blue and fluorescent pink) on warm cream paper. Flat shapes, thick friendly outlines, inks overprint where they overlap, soft paper grain.

- Mood: playful, printed, warm, slightly imperfect, zine
- Palette: bg `#F4ECDD`, ink `#24479A`, accent1 `#FF5C8D`, accent2 `#9FBBEA`, paper `#FFF9EF`
- Font: bricolage-grotesque-800 · default background: solid · texture: grain · shadow: none

## Raw SVG (escape hatch)

`{"id": "x", "component": "raw", "at": "center", "props": {"width": 200, "height": 120}, "svg": "<path class=\"r-accent\" d=\"…\"/>"}` — drawn in a local 0..width × 0..height box. Max 8 KB each, max 3 per scene, no `<text>`/`<style>`/scripts, palette colors only. Ids are namespaced automatically. Good raw shapes can be promoted to components (label `component-proposal`).
